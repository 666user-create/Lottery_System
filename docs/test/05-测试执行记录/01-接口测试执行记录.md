## 2. 关键定性证据（真实响应原文）

### 2.1 契约 C-3 定性（并纠正首轮错误记录）

```
[定性] 不存在活动 → HTTP=200 code=202 msg='查询活动详细失败'
```
**服务端日志互印**：
```
20:00:14 [http-nio-8080-exec-9] ERROR GlobalExceptionHandler - 控制器异常
org.example.lottery_system.common.exception.ControllerException: 查询活动详细失败
    at ActivityController.convertToGetActivityDetailResult(ActivityController.java:65)
```
→ **首轮记录的"200+null"不成立**，缺陷 BUG-003 **撤销**。

### 2.2 契约 C-1 定性（分页参数名分裂）

服务端日志中，两次请求（第二次传 `page=2`）绑定结果均为默认值：
```
20:00:14 ActivityController - findActivityList: {"currentPage":1,"pageSize":2}
20:00:14 ActivityController - findActivityList: {"currentPage":1,"pageSize":2}
```
→ 证实 `page` 参数被**静默忽略**（`PageParam` 只接 `currentPage`）；`user-lobby.html:164` 传 `pageNum` 亦不生效。

### 2.3 BUG-007 定性（邮箱大小写）

```
执行前：[定性] 含大写字母邮箱注册 → code=101 message='邮箱校验失败'
修复后：code=200（注册成功），且新账号可正常登录
```

### 2.4 BUG-008/009 定性（异常处理与信息泄露）

**修复前**（原文节选）：
```
code=500 msg="### Error updating database.  Cause: java.sql.SQLIntegrityConstraintViolationException:
Column 'question' cannot be null ### SQL: insert into faq(question, answer, category) values(?, ?, ?)
### The error may exist in org/example/lottery_system/dao/mapper/FaqMapper.java"
```
```
code=500 msg="Required request body is missing: public org.example.lottery_system.common.pojo.CommonResult<...>
org.example.lottery_system.controller.UserController.userPasswordLogin(org.example...UserPasswordLoginParam)"
```
**修复后**：分别返回 400（请求体格式错误）/ 415（不支持的请求类型）/ 404（资源不存在），响应不含任何内部细节。

### 2.5 C-2 定性（分页越界）

**修复前**：
```
code=500 msg="### SQL: select * from activity order by id desc limit ?,?
### Cause: java.sql.SQLSyntaxErrorException: ... near '-10,10'"
```
**修复后**：`code=400`（当前页不能小于1 / 每页数量不能小于1）。

### 2.6 身份参数覆盖语义（契约要点）

```
[定性] 请求 identity='SUPERADMIN'(非法枚举值) → code=200
[定性] 实际入库身份 = 'NORMAL'
```
→ 服务端策略**正确覆盖**（防提权）；契约缺口：客户端被静默忽略，无提示。详见 `contract/api-contract.md`。

## 5. 反向验证记录（第⑤步核心）
