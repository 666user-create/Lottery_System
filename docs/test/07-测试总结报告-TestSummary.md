## 4. 反向验证（本轮新增的质量保证手段）

针对业主规则 #3（"假通过的断言不算测过"），执行**故意破坏 → 断言必须失败**：

| 破坏点 | 预期 | 实测 |
|---|---|---|
| 邮箱正则改回 `[a-z0-9]` | 大写邮箱用例失败 | ✅ FAILED |
| `PageParam` 移除 `@Min` | 4 条分页边界用例失败 | ✅ FAILED（返回 500 + SQL 原文） |
| 兜底恢复 `e.getMessage()` | 泄露检测用例失败 | ✅ FAILED |

**破坏版结果：6 failed / 4 passed**（正常值 currentPage=1/2 仍通过，证明失败可归因）；
**还原后：146 passed / 1 xfailed** —— 断言有效性得到闭环证明。
