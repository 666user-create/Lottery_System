## 4. 测试数据清理工具与当前基线（2026-10-20 实测）

### 4.1 清理工具

```powershell
cd tests\api
python tools\db_cleanup.py            # 干跑：只列出将被删除的行
python tools\db_cleanup.py --apply    # 实删（自动先备份 .sql）
```

- **白名单前缀**：`qa_auto_` / `QA_AUTO_`（测试数据一律带此后缀，清理工具只认此前缀）。
- **备份**：`--apply` 前自动导出 `.sql` 备份，命名规则为「日期时间 + `.sql`」，只保留最新一份。
- **保护对象**：`spring_ai_chat_memory` 中的历史会话、非白名单业务数据一律不动。
