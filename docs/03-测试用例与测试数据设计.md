# 测试用例集（全模块）

## 使用说明

1. **用例编号规则**：`TC-<模块>-<序号>`，模块缩写：`USR`（用户）、`ACT`（活动）、`PRI`（奖品）、`DRW`（抽奖）、`AIC`（AI客服）、`FAQ`（知识库）、`HOV`（交接班）、`SEC`（安全权限）、`CMP`（公共组件）。
2. **优先级**：P0 冒烟 / P1 核心 / P2 常规 / P3 体验。
3. **测试数据**：使用《04-测试环境与数据配置说明.md》中定义的账号与数据。
4. **执行痕迹**：每个用例的执行结果记录在《05-测试执行与缺陷跟踪清单.md》与 `明细/执行报告/` 中，与用例编号一一对应。
5. **缺陷关联**：执行发现缺陷时，记录缺陷编号（BUG-XXX，见缺陷报告）。
